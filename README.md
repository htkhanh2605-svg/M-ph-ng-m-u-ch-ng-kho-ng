# StockVerse

Website static phân tích giá cổ phiếu theo phiên, tháng, quý và xu hướng năm. Trang dùng HTML/CSS/JavaScript thuần; không cần cài dependencies hoặc chạy build.

## Chạy website

Mở `static/index.html` bằng trình duyệt hoặc chạy một static server tại thư mục gốc, ví dụ:

```sh
python -m http.server 8000
